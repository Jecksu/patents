# 永久命名质量门控与关系闭包补充现有技术核查

## 1. 核查目的与边界

本报告补充核查“永久命名质量指标与 CAD 模型差异计算增强设计”可能采用的新增强化点，重点关注：

1. 使用既有 CAD 永久命名或实体标识比较两个模型或版本；
2. 使用高置信匹配作为锚点扩展低置信匹配；
3. 在匹配完成后识别新增和删除；
4. 在拓扑变化后传播或转移 persistent identifier；
5. 保留名称—实体多重关系、冻结未决端点，并统一处理一对一、分裂和合并关系。

本报告以专利全文及其独立权利要求为主要证据，仅用于申请前技术方案和权利要求布局分析，不构成新颖性、创造性或授权结论。正式提交前仍应由专利代理人按最终独立权利要求在官方数据库中复检。

## 2. 结论摘要

- “高置信匹配作为低置信匹配锚点”已经被 `US10816957B2` 的说明书公开。
- “匹配完成后再把剩余实体标记为新增或删除”与 `US10816957B2` 的独立权利要求和说明书高度接近，不能单独承担创造性。
- “分阶段 B-rep 匹配、候选排序、普通一对一端点互斥、利用已匹配邻接签名迭代传播，以及将旧 persistent identifier 转移到新拓扑”已经被 `US20200218835A1/US11288411B2` 公开。
- 因此，“质量指标 + 锚点传播 + 普通候选匹配 + 后判增删”的宽泛组合具有中高创造性组合风险。
- 本轮没有发现单篇文献完整公开以下绑定组合：既有名称—实体集合值关系的映射基数保真；身份不变量与允许变化属性分离；基于映射基数和身份一致性的状态门控；未决端点冻结；一对一／一对多／多对一关系假设联合互斥选择；双侧分区不变量检查；失败后回滚或局部扩读；闭包后判定增删。

## 3. 最接近的新增文献

### 3.1 US10816957B2

来源：[US10816957B2 - System and method for persistent identification of CAD model entities](https://patents.google.com/patent/US10816957B2/en)

独立权利要求的核心包括：

1. 获取两个版本的 CAD 文件及各自实体标识；
2. 匹配两个模型中的面；
3. 将第二版本的标识映射回第一版本标识；
4. 在共有面完成匹配后识别新增或删除实体；
5. 稳定匹配面标识，形成虚拟永久标识并输出集成 CAD 文件。

说明书还公开：

- 使用高概率、已经确认的面匹配辅助识别低概率匹配；
- 在其他面完成匹配或识别后，将剩余面标记为新增或删除。

与拟强化方案的主要区别：

- 未见把名称—实体关联保存为集合值的多重关系，并同时保留键侧和实体侧映射基数；
- 未见明确分离身份不变量与允许发生变化的尺寸、参数或修剪属性；
- 未见根据名称映射基数和身份一致性生成可信、歧义、冲突、低信息状态；
- 未见在同一选择模型中统一处理一对一、一对多和多对一关系；
- 未见单独冻结未决端点，使其既不进入确定关系也不进入新增／删除；
- 未见双侧分区不变量失败后撤销低置信关系或扩大局部数据读取范围。

风险评价：高。锚点传播和“匹配完成后判增删”均不能单独作为本案创造性核心。

### 3.2 US20200218835A1 / US11288411B2

来源：

- [US20200218835A1 - Persistent identification of CAD model entities](https://patents.google.com/patent/US20200218835A1/en)
- [US11288411B2 - 授权文本](https://patents.google.com/patent/US11288411B2/en)

独立权利要求的核心包括：

1. 导入新的 B-rep，并选择旧 CAD 模型；
2. 根据体积、包围盒和实体数量生成体签名；
3. 计算候选体相似度并排序；
4. 仅在两个体均未被其他候选占用时记录候选匹配；
5. 依次执行精确重合、重叠和邻接匹配；
6. 使用已匹配实体索引形成未匹配实体的邻接签名，并迭代传播匹配；
7. 根据匹配拓扑将旧模型引用解析到新模型。

说明书还公开：

- 匹配的新拓扑可以继承旧 persistent identifier；
- 当新邻接签名对应多个旧签名时，可以重建队列继续处理。

与拟强化方案的主要区别：

- 未见读取并保存既有永久名称的多对多关联关系；
- 未见将身份不变量和允许变化属性用于不同判断阶段；
- 唯一候选或多候选处理不是由名称映射基数、名称质量状态和身份一致性联合驱动；
- 端点互斥主要用于普通一对一候选，未见一对一和分裂／合并组关系假设的联合选择；
- 未见冻结未决端点并禁止其进入新增／删除；
- 未见双侧分区不变量及失败后的关系回滚或局部扩读。

风险评价：高。普通候选评分、排序、一对一端点互斥、邻接签名锚点传播以及 persistent identifier 转移均已受到强现有技术压力。

## 4. 既有永久命名和 CAD 差异文献复核

### 4.1 US6445388B1

来源：[US6445388B1 - Tolerant persistent naming for loft features](https://patents.google.com/patent/US6445388B1/en)

独立权利要求的核心包括：

- loft 由有序截面及其 segments 构成；
- 每个 segment 分配唯一 persistent name；
- 建立 cross-section matrices；
- 通过 similarity analysis 和矩阵更新，使名称容忍 loft 的局部拓扑变化。

该文献保护永久名称的生成、保存和更新，没有公开对两个 CAD 版本执行名称质量门控、未决冻结、统一谱系关系选择或差异闭包。

风险评价：中等。永久命名、相似性消歧和拓扑分裂均属于成熟背景，本案必须继续限定为读取比较前已经存在的永久命名关系，并不得以生成或更新永久名称为核心。

### 4.2 US7206661B2

来源：[US7206661B2 - Persistent naming for sub-paths of intermittent fillet weld beads](https://patents.google.com/patent/US7206661B2/en)

独立权利要求的核心包括：

- 接收间歇角焊缝连续路径；
- 确定不变焊缝生成方向；
- 划分基本等长、等距的子路径；
- 按不变方向命名子路径及其边和顶点。

该文献限定于焊缝路径的永久命名生成，没有两个模型的差异计算、命名可靠性状态、异常关系选择或关系闭包。

风险评价：中低，主要用于证明基于不变量生成稳定名称已经属于成熟技术背景。

### 4.3 US10192023B2

来源：[US10192023B2 - CAD comparison tool](https://patents.google.com/patent/US10192023B2/en)

独立权利要求的核心包括：

- 接收表示同一部件的两个 CAD 模型；
- 比较直接对应元素的位置值；
- 形成并显示差异列表；
- 接收忽略或确认差异的用户操作。

该文献默认两侧元素已经直接对应，没有解决不可靠永久名称下如何建立对应关系，也没有多重映射、分裂／合并、未决冻结或关系闭包。

风险评价：中低，主要压缩“两模型直接对应比较 + 差异列表 + 人工确认”的宽泛表达。

## 5. 对强化方案的权利要求影响

### 5.1 不应继续作为独权核心的特征

- 高置信匹配作为低置信匹配锚点；
- 通过邻接签名迭代扩展匹配；
- 普通候选评分、排序和一对一端点互斥；
- 在匹配完成后把剩余实体确定为新增或删除；
- 向新拓扑传播或转移 persistent identifier；
- 泛化的“实体摘要 + 局部验证 + 输出差异”。

这些内容可以作为从属项、实施方式或与本案质量门控结合的补充手段，但不能孤立承担创造性。

### 5.2 建议绑定为独权核心的技术闭环

1. 从比较开始前已存在的永久命名索引建立实体—比较规范键关联关系，并保留一个键关联多个实体以及一个实体关联多个非等价键的映射基数；
2. 将实体身份不变量与允许发生设计变化的几何、参数或修剪属性分开处理；
3. 根据双侧映射基数、命名域元数据、身份一致性和数据可用性生成可信、歧义、冲突或低信息状态；
4. 同时形成一对一、一对多和多对一候选关系假设，并在双侧端点共享互斥约束下选择通过验证的关系；
5. 将候选竞争未决、验证数据缺失或局部读取失败的端点置入待复核冻结集合；
6. 对最终关系和冻结集合执行双侧分区不变量检查；
7. 检查失败时撤销低置信关系、扩大失败局部的 CAD 数据读取范围或将相关端点转入冻结集合，然后重新验证；
8. 只有关系端点与未决端点闭包成立后，才把其余旧侧端点确定为删除、其余新侧端点确定为新增。

### 5.3 需要保留的技术效果因果链

- 映射基数保真防止普通名称集合去重导致重复名称信息丢失；
- 身份和变化两阶段判断防止合法尺寸变化被误判为名称漂移或名称复用；
- 组关系和一对一关系联合选择防止分裂／合并端点被普通一对一匹配提前占用；
- 未决冻结防止读取失败或候选竞争对象被错误计为新增／删除；
- 分区不变量驱动关系回滚或局部扩读，使其成为控制算法而不是结果展示公式；
- 完成闭包后再分类，使双侧实体结果可复算且不会重复计数。

## 6. 剩余风险与复检建议

1. 本轮没有发现单篇文献完整覆盖第5.2节的八项绑定组合，但“未发现”不等于不存在。
2. `US10816957B2` 与 `US11288411B2` 可以和永久命名质量评价、图匹配或集合闭包文献组合评价，创造性风险仍为中等，不能表述为低风险或保证授权。
3. 正式提交前，应使用最终独立权利要求逐项检索“persistent identifier reliability/confidence/conflict”“many-to-many entity-name mapping”“split merge correspondence”“unresolved endpoint”“partition invariant”“rollback validation”等中英文组合。
4. 应由代理人确认负面限定“比较过程不生成或更新永久命名规则”的支持方式，以及算法特征与 CAD 数据读取、候选缩减、局部 B-rep 验证和误分类控制之间的技术效果联系。
5. 本次没有完成对 CNIPA 官方《专利审查指南》最新文本的逐条引用；正式落稿时应补核算法特征、说明书充分公开、权利要求支持和清楚性要求。
