## 1. US10816957B2

来源：https://patents.google.com/patent/US10816957B2/en

| 项目 | 内容 |
|---|---|
| 名称 | CAD integration through virtual persistent identifiers and design change recognition |
| 专利号 | US10816957B2（公开号 US20180259937A1） |
| 发明人 | Robert Kirkwood |
| 申请人 | **个人**（原始及当前均为个人，非企业） |
| 申请号 | US15/456,475 |
| 申请日／优先权日 | 2017-03-10 |
| 公开日 | 2020-10-27（授权）／2018-09-13（申请公开） |

### 独权数量：**仅 1 项**（授权时只有一条权利要求）

独权 1 为「集成对某制造部件的 CAM 软件应用文件变更的方法」，步骤：

1. 取得第一 CAD 文件，其含与部件实体（含面）关联的第一标识集合；
2. 显示由第一文件导出的第一实体模型；
3. 取得第二 CAD 文件，含该部件修订版本的第二标识集合；
4. 显示由第二文件导出的第二实体模型；
5. 将第二模型上的一个或多个面与第一模型的面相匹配；
6. 用 design change vector (DCV) 软件程序把第二标识集合还原为第一文件的标识；
7. **在两模型共有的全部面完成匹配后，识别被新增或删除的实体**；
8. 稳定已匹配面的标识，其结果称为 virtual persistent identifiers；
9. 经 DCV 程序以至少三个选项实现该标识：(i) remap 建立第一到第二标识集合的映射表；
   (ii) indirection 建立第一实体模型与接收应用之间的转换表；(iii) redirection 改变
   第二标识集合而不建立到下游工程应用的引用表；
10. 用 DCV 程序确定并实现的 virtual persistent identifiers 输出集成后的接收 CAD 文件。

### 核对结论

supplement 对第 7 步「共有面完成匹配后识别新增或删除」的摘录**准确**，该特征确实
写在独立权利要求中，本案对此的应对（CLOSURE_PASS ＋ 同代次端点级失败凭证）方向正确。

**supplement 未记录、但影响评价的三点**：

1. **该专利只有一条权利要求**，且其中大量篇幅是 DCV 程序的三个实现选项
   （remap／indirection／redirection）与「输出集成后的接收 CAD 文件」。其发明目的是
   **跨应用的关联性维持与文件集成**，而非两版本差异判定本身。本案独权 1 的输出是
   类型化差异事件，不输出集成 CAD 文件，这是一处**可主张的目的差异**，supplement 未提。
2. 申请人为个人而非企业，2017 年申请日。
3. 授权文本中 (iii) 选项存在明显笔误（大致读作 "does not does build a reference table"）。

## 2. US11288411B2 / US20200218835A1

来源：https://patents.google.com/patent/US11288411B2/en

| 项目 | 内容 |
|---|---|
| 名称 | B-rep matching for maintaining associativity across CAD interoperation |
| 专利号 | US11288411B2（公开号 US20200218835A1） |
| 申请人 | **PTC Inc.** |
| 发明人 | Ilya Baran、Adriana Schulz |
| 申请号 | US16/735,194 |
| 申请日 | 2020-01-06 |
| 优先权日 | 2019-01-04（临时申请 62/788,338） |
| 公开日 | 2022-03-29（授权）／2020-07-09（申请公开） |

### 独权数量：**2 项（权 1 与权 2）**

- **权 2** 为宽版框架，五步：导入新模型 B-rep；选择既有模型为旧模型；计算刚体变换
  以对齐旧新模型拓扑；通过寻找旧新模型间重合的底层几何曲线与曲面匹配重叠拓扑；
  用已匹配拓扑把为旧模型配置的引用解析到新模型内以施加特征与约束。
- **权 1** 为同一五步骨架，但把对齐与匹配步骤展开为大量具体数值限定
  （从属权 3–19 的内容被并入独权）：

  *体匹配／刚体运动*：每体签名为**五个数的向量**（体积、包围盒对角线长度、顶点数、
  棱边数、面数）；四个阈值判定候选（体积在十倍以内、包围盒对角线在二倍以内、
  顶点／棱边／面数的较大者不超过一百加较小者的二倍）；候选相似度综合体积比、
  包围盒体积比、实体计数与平移前包围盒重叠体积比；**按该分数排序**。

  *平移搜索*：按相似度递减迭代，**仅处理两体均未被匹配的对**；体表示为全部顶点加
  棱边与面质心的点云；在随机旋转坐标系下向三轴投影解一维对齐问题（点数少于 100 时
  取全部两两差值排序后取最频值；100 及以上时先采样）；过半点对齐才算匹配。

  *顶点／棱边／面匹配，三阶段*：
  - **精确**：三维网格近邻结构找质心匹配的边／面对，再确认拓扑在容差内重合；
  - **重叠**：未匹配的同曲线棱边对在重叠长度达较短边 **80%** 时匹配，同曲面拓扑面对在
    重叠面积达较小面 80% 时匹配；旧模型棱边编码为表示向量（直线 6D、圆 7D、椭圆 11D），
    面为平面 4D、圆柱 7D、圆锥 7D、球 4D、环 8D，存入对应维度的网格最近邻结构；
  - **邻接**：每个已匹配对获得**任意唯一正整数作为 match index**；对未匹配的旧模型实体
    构建**邻接签名数组**（顶点遍历相邻边与面记录 match index、未匹配负指示、无面负指示；
    棱边同理；面则识别并遍历全部环，每环构建遍历数组、旋转至字典序最大处起始、
    数组间按字典序排序、以负的环分隔符拼接）；旧签名入哈希表，新模型签名入
    **按已匹配／未匹配实体比排序的队列**；取队首与哈希表比对，匹配则传播到底层
    顶点／边／面，并**更新两模型中相邻未匹配实体的邻接签名，重复至队列空或不再出现新匹配**。

### 核对结论

supplement 的摘录**准确且方向正确**，尤其两处对本案关键：

1. **「仅在两体均未被其他候选占用时记录候选匹配」确实在独权 1 中**，且整个流程是
   *按相似度排序 → 逐对占用 → 精确／重叠／邻接三阶段依次进行*。这正是本案权 1 步骤四
   与权 20/37 所反对的顺序，**构成对本案的反向教导（teaching away）**，是本案最有力的
   创造性论据。本次核对确认该论据成立。
2. **邻接签名迭代传播与 persistent identifier 转移确实已公开**，因此本案把锚点传播、
   邻接签名传播写为可选实施方式（权 35、36、实施方式十四）是正确处置。

**supplement 未记录、但值得注意的一点**：权 1 载入了极多具体数值限定（五数向量、
十倍／二倍／一百加二倍、80%、6D/7D/11D/4D/8D、100 点门限）。这意味着 **US11288411B2
的独权保护范围实际很窄**，其宽版是权 2。评价本案创造性时，审查员更可能引用其
**说明书**而非独权——supplement 结论「不能单独承担创造性」的判断因此仍然成立，
但论证时应针对说明书公开内容，而不是把独权 1 的窄范围当作压力来源。
