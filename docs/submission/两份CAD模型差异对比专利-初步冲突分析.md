# 两份CAD模型差异对比专利的初步冲突分析

> 说明：本报告基于公开网络检索结果和当前两份申请文件的权利要求草案进行技术冲突初筛，不构成正式法律意见、自由实施意见或无效检索结论。正式提交前仍建议由专利代理人做 CNIPA、Google Patents、WIPO、USPTO、EPO 等数据库的系统检索。

## 1. 待分析方案

### 方案A：轻量化多层摘要与变换归一化版本

核心链路为：

1. 获取第一CAD模型和第二CAD模型；
2. 提取全局摘要、局部实体摘要、语义摘要和关系摘要；
3. 判别刚体、相似或仿射变换；
4. 执行位姿、尺度或仿射归一化，或者记录全局差异；
5. 基于摘要索引生成候选匹配实体集合；
6. 局部验证实体级差异；
7. 聚合为设计语义级差异。

### 方案B：永久命名核心版本

核心链路为：

1. 获取两个CAD模型；
2. 获取永久命名实体索引；
3. 基于永久命名标识执行集合运算；
4. 对共有实体比较版本指纹或实体摘要；
5. 对候选变化实体执行局部验证；
6. 基于实体依赖关系执行语义聚合和影响传播；
7. 对命名异常或跨系统命名映射进行辅助处理。

## 2. 初步检索到的相关公开文献

### 2.1 CAD模型差异分析/模型对比方向

1. CN116433837B / US20240338501A1：一种基于关键点匹配的三维CAD模型差异分析方法。
   - 公开要点：将三维CAD模型转换为STP格式；提取顶点、边控制点、面控制点；构建图表示并进行图匹配；通过误匹配消除得到刚体变换参数；再基于关键点匹配序列分层比较顶点、边、面和实体差异。
   - 与方案A关系：高度相关，尤其覆盖了“关键点/图匹配/刚体变换/分层差异分析”。

2. CN114169031B：一种基于CAD的模型一致性自动比对方法及系统。
   - 公开要点：将待比对模型和标准模型转换为统一STP格式，再进行模型一致性自动比对。
   - 与方案A关系：相关，覆盖统一中间格式和一致性比较流程，但从检索摘要看未突出多层摘要、仿射变换判别和设计语义聚合。

3. US20180330042A1 / US10192023B2：Model comparison tool。
   - 公开要点：接收第一/第二CAD模型；比较CAD模型元素的位置值、几何、定义、注释等；识别差异；生成并显示 discrepancy list。
   - 与两个方案关系：属于宽泛CAD模型差异展示/审查工具，可能作为背景和宽范围现有技术。

4. CN109685147B：一种基于三维模型的差异性对比方法。
   - 公开要点：面向三维模型变更后的差异性对比，尤其工程制图/模具变更场景。
   - 与方案A关系：中等相关，需要进一步看权利要求是否涉及摘要索引、变换归一化或语义聚合。

5. CN111008429B：一种基于点云的异构CAD几何一致性对比方法。
   - 公开要点：将CAD模型线、面分割获取点云数据，通过点到线/面距离检测转换或重建模型几何精度。
   - 与方案A关系：相关于异构CAD和几何一致性，但技术路径是点云距离检测，不同于多层摘要和语义聚合。

6. CN119312543B：基于BREP的CAD模型对比方法、设备和存储介质。
   - 公开要点：先进行可视化比较；若一致再比较两个CAD模型的BREP数据。
   - 与方案A关系：相关于BREP模型对比，但目前检索摘要未显示“多层轻量摘要 + 变换判别 + 候选索引 + 语义聚合”的完整组合。

7. US7761265 / US20030208285A1：Method for comparing solid models。
   - 公开要点：选择特征表示solid model，抽取特征，构建无向模型依赖图，基于特征/依赖图判断solid model相似性。
   - 与方案A关系：对“语义摘要、关系摘要、特征依赖图、模型相似度”构成强背景技术。

### 2.2 永久命名/拓扑命名方向

1. US6445388B1：Tolerant persistent naming for loft features in a parametric feature-based, solid modeling system。
   - 公开要点：面向参数化特征建模系统中的loft特征，进行容错永久命名。
   - 与方案B关系：高度相关于永久命名本身，但不是模型差异对比流程。

2. US7206661 / US20050071042A1：Persistent naming for sub-paths of intermittent fillet weld beads。
   - 公开要点：对间断角焊缝路径子段及其边/顶点进行永久命名，使其在模型重算和拓扑变化下保持唯一和稳定。
   - 与方案B关系：高度相关于特定对象的永久命名，但不是以命名集合运算驱动模型差异识别。

3. “Mechanisms of Persistent Identification of Topological Entities in CAD Systems: A Review”及中文“支持协同CAD的拓扑实体永久命名机制”等论文。
   - 公开要点：拓扑实体永久标识/永久命名机制、协同CAD中的拓扑实体追踪。
   - 与方案B关系：作为永久命名的基础现有技术，对“永久命名系统本身”的新颖性不利，但不直接覆盖差异对比的完整处理链。

4. CN114818022A：一种用于参数化造型系统的元素记录方法。
   - 公开要点：参数化造型系统中的元素记录/追踪相关。
   - 与方案B关系：相关于元素记录和持久追踪，需要进一步核查是否涉及命名继承、历史追踪和差异比较。

5. “拓扑元素层次化命名方法与机制设计”等中文论文/公开。
   - 公开要点：拓扑元素层次化命名、命名继承机制。
   - 与方案B关系：对“永久命名索引结构”的宽泛权利要求有一定创造性压力。

## 3. 冲突风险评估

### 3.1 方案A：轻量化多层摘要与变换归一化版本

综合风险：中等偏高。

主要风险来自 CN116433837B / US20240338501A1。该公开已经覆盖：

1. CAD模型差异分析；
2. STP统一格式；
3. 关键点表示；
4. 图表示和图匹配；
5. 刚体变换参数估计；
6. 顶点、边、面、实体的分层差异识别。

因此，方案A如果主权利要求仅写成“提取摘要、估计变换、候选匹配、局部验证、输出差异”，容易被认为是上述关键点匹配/图匹配差异分析与传统形状描述子、特征图、局部验证技术的直接组合。

方案A仍有可区分空间：

1. 不局限于关键点、NURBS控制点或刚体变换，而是明确“全局摘要、局部实体摘要、语义摘要、关系摘要”的多层协同。
2. 明确处理“刚体、相似、仿射”三类变换，并把不可归一化仿射变换作为全局形变差异输出。
3. 明确候选匹配不是全量图匹配，而是摘要索引生成候选集合后局部验证。
4. 明确将实体级差异聚合为设计语义级差异，例如孔、倒角、阵列、槽、筋、装配约束变化。
5. 明确复杂度优势来自“摘要索引筛选 + 局部验证”，而不是单纯关键点匹配。

结论：方案A可以申请，但主权利要求需要进一步收窄和突出组合特征，尤其要避开 CN116433837B 的“STP + 顶点/边控制点/面控制点 + 图匹配 + 刚体变换 + 分层比较”路线。

### 3.2 方案B：永久命名核心版本

综合风险：中等。

永久命名本身不是新点，已有大量公开，包括 Autodesk 相关永久命名专利、拓扑实体永久标识论文、协同CAD永久命名机制等。因此，方案B不能把发明点写成“为CAD实体生成永久命名”或“基于永久命名追踪实体”。

方案B的可保护点在于把永久命名用于差异对比的完整处理链：

1. 获取两个模型的永久命名实体索引；
2. 对永久命名标识做集合运算，直接识别新增、删除、共有实体；
3. 对共有实体比较版本指纹或实体摘要，只筛出候选变化实体；
4. 对候选变化实体执行局部验证；
5. 根据实体依赖关系进行设计语义聚合；
6. 对命名冲突、命名失效、跨系统命名映射做辅助摘要匹配。

该组合没有在初步检索中被单个文献完整覆盖。US6445388B1、US7206661主要是“如何命名”；US20180330042A1主要是“如何展示/管理差异列表”；US7761265主要是“特征/依赖图相似性”。方案B的创造性应集中在“命名集合运算 + 指纹筛选 + 局部验证 + 依赖传播/语义聚合 + 命名异常处理”的流水线。

结论：方案B的可申请性略好于方案A，但必须承认永久命名为既有基础技术，并避免把永久命名生成机制写成主发明点。

## 4. 两份申请的相互关系与布局建议

建议保留两件案子，但定位不同：

1. 方案A作为“跨内核/无可比永久命名场景”的通用差异分析案。
2. 方案B作为“同一命名域/版本链/企业统一命名域场景”的高效率差异分析案。

两案之间应避免互相破坏创造性：

1. 方案A中永久命名只作为可选辅助，不作为必要条件。
2. 方案B中轻量摘要只作为版本指纹、局部验证和命名异常回退，不作为主匹配机制。
3. 两案标题和主权利要求应明显区分，避免审查员认为只是同一发明的等同包装。

## 5. 建议修改方案

### 5.1 方案A建议

将主权利要求进一步限定为：

1. 多层摘要至少包括“局部实体摘要 + 关系摘要 + 语义摘要”，不要只写“摘要”。
2. 变换处理至少包括“刚体/相似/仿射变换判别”和“不可归一化仿射变换作为全局差异输出”。
3. 候选匹配要写成“摘要索引生成候选集合”，不要写成泛泛“图匹配”。
4. 语义聚合要成为主权利要求必要步骤，而不是从属项。
5. 避开“提取顶点、边控制点、面控制点”和“NURBS控制点图匹配”措辞。

### 5.2 方案B建议

将主权利要求进一步限定为：

1. 永久命名实体索引包括永久命名标识、实体类型、实体依赖关系和版本指纹。
2. 通过集合运算识别新增、删除、共有实体。
3. 对共有实体用版本指纹筛选候选变化实体。
4. 仅对候选变化实体局部验证。
5. 通过实体依赖关系进行语义聚合和影响范围传播。
6. 命名异常检测和摘要辅助匹配可放入从属权利要求。

## 6. 初步结论

1. 两份方案都不是“完全无冲突”的空白领域，CAD模型对比、三维模型差异分析、形状描述子、图匹配、永久命名都有较多现有技术。
2. 方案A的最大冲突点是 CN116433837B / US20240338501A1。需要把差异点从“关键点/刚体配准/分层比较”转移到“多层轻量摘要、仿射判别、摘要索引候选筛选、设计语义聚合”。
3. 方案B的最大冲突点是永久命名基础技术已公开。需要把创新点放在“利用永久命名做差异对比加速的完整处理流水线”，而不是“永久命名本身”。
4. 从当前初筛看，方案B的授权可操作性略高；方案A的保护范围更宽，但需要更精细地避让关键点匹配和BREP/点云/一致性比较类现有技术。
5. 正式提交前建议做一次权利要求级检索，特别核查 CN116433837B、CN114169031B、CN119312543B、CN111008429B、US20180330042A1、US7761265、US6445388B1、US7206661 的独立权利要求。

## 7. 已按检索结果调整的方案A侧重点

根据上述检索结果，方案A已调整为“面向跨CAD内核的基于轻量化多层摘要的CAD模型差异快速筛选与对比方法及系统”。新的侧重点为：

1. 明确主场景为跨CAD内核、跨文件格式、永久命名不可比较或不可用的模型对比。
2. 明确不在初始阶段执行完整BREP实体逐项比较，而是在BREP精确比较之前先提取轻量化多层摘要。
3. 通过摘要索引筛除摘要相似度不足、语义摘要不一致或关系摘要不满足局部关联条件的不相关特征或实体。
4. 仅对未被筛除的候选实体执行局部验证；必要时才读取候选邻域的局部BREP数据。
5. 继续保留位姿、尺度、仿射变换判别，以及实体级差异到设计语义级差异的聚合。

该调整有利于避开 CN116433837B / US20240338501A1 的“关键点匹配 + 图匹配 + 刚体变换 + 分层比较”主路线，也有利于区别 CN119312543B 等BREP对比类方案。
