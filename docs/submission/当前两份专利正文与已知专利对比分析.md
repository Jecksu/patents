# 当前两份专利正文与已知专利对比分析

> 本报告基于当前两份专利正文、前次指定8件现有专利的独立权利要求级核查结果以及本地已知专利材料形成，用于技术方案调整和代理人沟通，不构成正式法律意见、侵权意见或无效检索结论。

## 一、对比对象

### 1.1 当前我方专利正文

1. 轻量化摘要版：`一种面向跨CAD内核的基于轻量化多层摘要的CAD模型差异快速筛选与对比方法及系统`
   - 当前核心：跨CAD内核、永久命名不可比较或不可信、初始筛选阶段不执行完整BREP实体逐项比较、多层轻量化摘要、摘要闸门、凸包粗过滤、候选局部验证、仿射/位姿/尺度处理、设计语义聚合。
2. 永久命名版：`一种基于CAD永久命名的模型差异对比方法及系统`
   - 当前核心：读取既有永久命名实体索引、判断同一命名域或既有映射关系、基于永久命名标识做集合运算、命名一致性审计、版本指纹/实体摘要筛选、命名异常闭环重分类、局部验证、设计语义聚合。

### 1.2 已知专利

1. CN116433837B：基于关键点匹配的三维CAD模型差异分析方法。
2. CN114169031B：基于CAD的模型一致性自动比对方法及系统。
3. CN119312543B：基于BREP的CAD模型对比方法、设备和存储介质。
4. CN111008429B：基于点云的异构CAD几何一致性对比方法。
5. US20180330042A1 / US10192023B2：Model comparison tool。
6. US7761265B2：Method for comparing solid models。
7. US6445388B1：Tolerant persistent naming for loft features。
8. US7206661B2：Persistent naming for sub-paths of intermittent fillet weld beads。

## 二、总体结论

当前两份正文已经形成较清楚的保护侧重点分离：

1. 轻量化摘要版与已知专利相比，最有授权价值的组合是：在跨CAD内核或永久命名不可比较场景中，不进入完整BREP实体逐项比较，而先通过多层轻量化摘要和摘要闸门筛除不相关特征或实体；凸包摘要只作为全局或局部外包络粗过滤手段；只有通过闸门的少量候选对象才进入局部验证或局部BREP读取。指定8件现有专利中未见单件完整公开该组合。
2. 永久命名版的风险仍高于轻量化摘要版，因为永久命名本身已有较多公开。当前正文通过“不生成永久命名、只读取既有永久命名索引”“同一命名域或既有映射关系”“集合运算 + 命名一致性审计 + 指纹筛选 + 命名异常闭环重分类 + 局部验证”把保护重点从永久命名生成机制转移到差异对比鲁棒流水线，创造性支撑比上一版更强。
3. 新增的“凸包匹配/凸包摘要”有助于支撑低复杂度粗过滤，但不宜作为任一方案的单独核心创新点。凸包属于常见几何描述方式，应继续限定为“粗过滤、排除明显无关对象、不能单独作为最终相同判定依据”。
4. 从授权稳定性看，轻量化摘要版更适合作为主案推进；永久命名版可作为同族或补充申请推进，但独立权利要求应保持对“既有命名索引差异处理流水线”的限定，避免被US6445388B1、US7206661B2等永久命名文献直接压缩。

## 三、轻量化摘要版对比分析

### 3.1 当前独立权利要求的关键区别链

轻量化摘要版权利要求1已经包含以下连续技术特征：

1. 确定两个CAD模型不存在可比较永久命名、永久命名缺失或永久命名不可信。
2. 在不执行完整BREP实体逐项比较的初始筛选阶段提取多层轻量化摘要。
3. 多层轻量化摘要来源于统计信息、轻量网格、实体属性、拓扑邻接统计或设计语义识别结果。
4. 基于摘要确定位姿、尺度或仿射变换关系，并执行归一化或输出全局差异。
5. 在完整BREP实体逐项比较之前生成摘要索引。
6. 通过全局摘要闸门、局部摘要闸门和关系摘要闸门中的至少两个筛除不相关特征或实体。
7. 仅对候选匹配实体集合执行局部验证，必要时只读取或比较候选实体邻域的局部BREP数据。
8. 将实体级差异聚合为设计语义级差异。

这条链路的重点不是“找一个几何相似度指标”，而是把差异比较拆成“轻量摘要预筛选 - 候选缩减 - 局部验证 - 语义聚合”，并把该流程限定在跨CAD内核、无可比永久命名和BREP前筛选场景中。

### 3.3 对“凸包粗过滤”的专门评价

当前正文中凸包被放在全局摘要、局部实体摘要和摘要闸门中，技术位置基本合理。它带来的正面作用是：

1. 能说明粗过滤阶段可以在不完整读取BREP的情况下利用外包络统计快速排除明显无关对象。
2. 能支撑复杂度降低：先通过凸包体积、凸包表面积、主轴、法向分布、支撑函数采样等摘要缩小候选集，再进行局部验证。
3. 能与跨CAD内核场景配合，因为凸包可来自轻量网格、采样点或实体外轮廓，而不强依赖特定CAD内核的拓扑命名。

但凸包本身不是强新颖点，残余风险包括：

1. 凸包、包围盒、体积、表面积、主轴等属于常见形状描述符，单独主张容易被认为显而易见。
2. 如果把凸包匹配写成最终相同/不同判定依据，可能被攻击为精度不足或常规几何筛选。
3. 如果凸包摘要依赖高密度采样点并进一步比较点距，容易被CN111008429B的点云距离路线牵引。

因此，当前正文中“凸包摘要用于粗过滤，不单独作为两个CAD模型完全相同的最终判定依据”的写法应保留；凸包应作为摘要闸门中的一个子特征，而不是独立权利要求的唯一发明点。

## 四、永久命名版对比分析

### 4.1 当前独立权利要求的关键区别链

永久命名版权利要求1已经限定：

1. 读取由CAD系统、CAD内核或PDM系统预先提供的永久命名实体索引。
2. 判断两个永久命名实体索引是否属于同一命名域，或者是否存在已建立的统一命名域映射关系。
3. 当属于同一命名域或存在映射关系时，才进入基于永久命名标识的差异对比流程。
4. 通过集合运算确定新增实体、删除实体和共有实体。
5. 对集合运算结果和共有实体执行命名一致性审计，生成命名正常实体集合和命名异常实体集合。
6. 对命名正常共有实体比较实体摘要或版本指纹，确定候选变化实体。
7. 对命名异常实体集合执行摘要辅助匹配和局部验证，并将异常实体重分类为新增、删除、修改、重命名、分裂、合并或命名异常待复核。
8. 基于实体依赖关系聚合为设计语义级差异。

这条链路的授权重点不是“CAD实体如何被永久命名”，而是“已有永久命名索引如何被审计、使用和纠偏，以降低模型差异对比复杂度，并避免错误永久命名直接导致差异误判”。

### 4.3 对“跨CAD系统永久命名映射”的评价

当前永久命名版中写有“当不同CAD系统已存在永久命名映射关系时，读取该映射关系并映射到统一命名域”。这个限定比较重要，因为它避免了把权利要求写成“任意不同CAD系统永久命名都可直接比较”。建议继续保持以下边界：

1. 不主张自动生成跨内核永久命名统一规则。
2. 不主张不同CAD内核天然具有可比永久命名。
3. 仅在已有统一命名域或已有映射关系时执行命名集合运算。
4. 对无法映射或命名异常的对象回退到实体摘要辅助匹配。

这样可以同时避开永久命名生成类现有技术，并避免与轻量化摘要版的“无可比永久命名”主线互相冲突。

### 4.4 对几何摘要的定位

永久命名版不再突出凸包过滤。几何摘要、外包络摘要等只作为命名一致性审计或摘要辅助匹配中的可选校验信息，其合理位置是：

1. 对版本指纹不同的共有实体或命名异常实体提供一致性校验。
2. 辅助生成替代候选集合。
3. 帮助判断是否需要进入局部几何、拓扑、参数或语义验证。

永久命名版的主发明点应当是“命名集合运算 + 命名一致性审计 + 版本指纹筛选 + 命名异常闭环重分类 + 候选局部验证 + 语义聚合”。几何摘要不宜被写成主线，更不应把凸包过滤作为该版本的突出卖点。

| US7761265B2 | 中 | 其公开依赖图和特征相似度，可能影响实体依赖聚合的创造性 |
| CN116433837B、CN119312543B | 中低 | 分别对几何匹配和BREP验证形成背景压力，但不是永久命名流水线核心 |

综合判断：永久命名版不宜被描述为“发明一种永久命名”。当前正文已经回避该风险，转而保护“既有永久命名索引驱动的差异对比鲁棒流水线”。新增的命名一致性审计和命名异常闭环重分类，使其不再只是“同名实体做集合/指纹比较”，而是解决错误永久命名导致差异误判的问题。该方向在指定8件文献中未见单件完整覆盖，但永久命名基础概念仍有较强现有技术压力。

## 五、两份正文之间的互补关系

| 维度 | 轻量化摘要版 | 永久命名版 |
| --- | --- | --- |
| 适用场景 | 跨CAD内核、跨格式、供应商模型、永久命名缺失/不可比较/不可信 | 同一CAD系统、同一版本链、同一命名域、已有跨系统命名映射 |
| 核心入口 | 多层轻量化摘要 | 既有永久命名实体索引 |
| 候选缩减方式 | 摘要索引、摘要闸门、凸包粗过滤、关系摘要闸门 | 命名集合运算、命名一致性审计、版本指纹、实体摘要 |
| 精确验证范围 | 通过摘要闸门的候选实体或候选邻域 | 版本指纹不同实体、命名异常实体和异常替代候选集合 |
| 主要现有技术压力 | CN116433837B、CN119312543B、CN111008429B、US7761265B2 | US6445388B1、US7206661B2、US20180330042A1、US7761265B2 |
| 授权稳定性 | 相对更强 | 中等，依赖权利要求限定是否清楚 |

两份正文可以形成较好的组合布局：轻量化摘要版保护“无可比命名时如何快速筛”，永久命名版保护“有可靠命名时如何快速比”。二者不宜互相覆盖过多，尤其是永久命名版不宜过度扩张到“无可比永久命名”的场景；轻量化摘要版也不宜把永久命名作为必要条件。

## 六、建议进一步保留的权利要求写法

### 6.1 轻量化摘要版

建议继续保留或强化以下表述：

1. “不存在可比较永久命名、永久命名缺失或永久命名不可信。”
2. “在不执行完整BREP实体逐项比较的初始筛选阶段。”
3. “在执行完整BREP实体逐项比较之前，基于归一化后的多层轻量化摘要生成摘要索引。”
4. “通过至少两个摘要闸门筛除不相关特征或实体。”
5. “凸包摘要用于粗过滤，不单独作为最终相同判定依据。”
6. “仅在局部验证需要精确几何确认时读取或比较候选实体邻域的局部BREP数据。”
7. “不以NURBS控制点关键点匹配、全模型点云距离比较或Ullmann子图同构作为必要步骤。”

当前正文已补强如下区别表达，建议在代理人定稿时继续保留：

> 所述摘要闸门输出的是候选关系或排除关系，而非基于关键点匹配、全模型图匹配或全量点云距离计算得到的最终实体对应关系。

### 6.2 永久命名版

建议继续保留或强化以下表述：

1. “永久命名实体索引由CAD系统、CAD内核或产品数据管理系统预先提供。”
2. “判断同一命名域或已建立的统一命名域映射关系。”
3. “当属于同一命名域或存在映射关系时，进入基于永久命名标识的差异对比流程。”
4. “不包括生成CAD实体永久命名标识的步骤。”
5. “集合运算确定新增、删除和共有实体。”
6. “版本指纹相同的命名正常共有实体跳过完整几何验证。”
7. “几何摘要和外包络摘要仅作为一致性审计或摘要辅助匹配的可选校验信息。”
8. “命名异常时执行实体摘要、关系摘要、语义摘要或外包络摘要辅助匹配。”
9. “将命名异常实体重分类为重命名、分裂、合并或命名异常待复核，并声明不更新CAD系统永久命名生成规则。”

可考虑在代理人定稿时增加一句更强的区别表达：

> 所述永久命名标识不用于构造或更新CAD系统的持久命名规则，而作为差异对比流程中的既有索引键参与集合运算、命名一致性审计、命名异常实体重分类和候选变化实体筛选。

## 七、当前通过概率的相对判断

在仅考虑指定8件现有专利的前提下，当前两份正文的相对判断如下：

1. 轻量化摘要版：授权概率相对更高。其区别点不依赖单一几何描述符，而是依赖跨CAD内核、无可比永久命名、BREP前摘要筛选、候选局部验证和语义聚合的组合。最大压力来自CN116433837B，需要在答复审查意见时突出“不是NURBS关键点/图匹配路线”。
2. 永久命名版：授权概率中等偏上。永久命名本身被US6445388B1和US7206661B2等文献充分公开，授权关键在于把权利要求限定为“读取既有命名索引后的差异处理鲁棒流水线”。新版最大增强点是命名一致性审计和命名异常闭环重分类，答审时应强调它解决的是错误命名导致的差异误判，而不是生成永久命名。
3. 凸包粗过滤：适合作为从属特征和效果支撑，不适合作为独立发明点。其价值在于帮助说明“越过完整BREP信息对比即可快速筛出不相关特征”，而不是证明最终几何一致。

## 八、下一步建议

1. 主案优先推进轻量化摘要版，并在答审策略中预设CN116433837B作为最接近现有技术。
2. 永久命名版可作为并行申请或补充布局，但应避免把“生成永久命名”写入核心技术方案。
3. 两案都应保留复杂度分析，将全量两两匹配或完整BREP逐项比较的近似O(n^2)与摘要索引/集合运算/候选局部验证的O(n)、O(n log n)或O(k)进行对比。
4. 轻量化摘要版已将“摘要闸门输出候选关系、排除关系或匹配置信度”“凸包仅粗过滤”“候选局部BREP验证”写入权利要求和说明书，建议代理人定稿时保留该必要闭环。
5. 永久命名版已将“命名域判断 + 集合运算 + 命名一致性审计 + 版本指纹跳过完整验证 + 命名异常闭环重分类”写入独权主链，建议代理人定稿时保留该闭环。
