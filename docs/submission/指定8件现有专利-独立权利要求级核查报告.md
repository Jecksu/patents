# 指定8件现有专利的独立权利要求级核查报告

> 说明：本报告基于公开网页、Google Patents 文本镜像、Justia、FreePatentsOnline、公开 PDF、搜索结果片段，以及用户提供的本地中文专利全文 PDF 进行独立权利要求级初筛。该报告用于技术方案调整和代理人沟通，不构成正式法律意见、侵权意见或无效检索结论。

## 1. 核查对象

本次按用户指定核查以下文献：

1. CN116433837B：一种基于关键点匹配的三维CAD模型差异分析方法。
2. CN114169031B：一种基于CAD的模型一致性自动比对方法及系统。
3. CN119312543B：基于BREP的CAD模型对比方法、设备和存储介质。
4. CN111008429B：一种基于点云的异构CAD几何一致性对比方法。
5. US20180330042A1 / US10192023B2：Model comparison tool。
6. US7761265B2：Method for comparing solid models。
7. US6445388B1：Tolerant persistent naming for loft features in a parametric feature-based, solid modeling system。
8. US7206661B2：Persistent naming for sub-paths of intermittent fillet weld beads。

当前我方方案：

- 方案A：一种面向跨CAD内核的基于轻量化多层摘要的CAD模型差异快速筛选与对比方法及系统。
- 方案B：一种基于CAD永久命名的模型差异对比方法及系统。

## 2. 独立权利要求要点

### 2.1 CN116433837B

证据来源：Google Patents 授权文本镜像；并以本地 `E:\code\专利\已知专利\CN202310337386_FullTextImage.pdf` 的 CN116433837A 公布文本交叉核对，独立权利要求1技术主线一致。

独立权利要求1要点：

1. 将待比较的两个三维CAD模型转化为STP格式。
2. 从三维CAD模型提取三类关键点：顶点、边控制点、面控制点。
3. 顶点来自边交点；边和面转化为NURBS形式，并提取NURBS控制点及权重。
4. 将三维CAD模型转化为图表达形式，模型每个面对应图节点，共边关系对应图连接边。
5. 计算两图节点和连接边相似度，基于NURBS均匀采样和刚体变换平均匹配距离误差。
6. 利用图匹配方法对两模型顶点预匹配，求总相似度最大的最优匹配矩阵。
7. 通过误匹配消除计算模型间刚体变换参数。
8. 匹配顶点、边控制点、面控制点三类关键点。
9. 逐层判断顶点、边、面和模型差异。

对我方方案A的影响：高相关。它已经覆盖“跨模型差异分析 + 图表示/匹配 + 刚体配准 + 分层实体差异识别”。我方A必须避免被写成关键点匹配或NURBS控制点匹配方案。

对我方方案B的影响：低到中等。该文献不以永久命名索引、命名集合运算、版本指纹筛选为核心。

### 2.2 CN114169031B

证据来源：Google Patents 授权文本镜像；并以本地 `E:\code\专利\已知专利\CN202111361688_FullTextImage.pdf` 的 CN114169031A 公布文本交叉核对。注意：授权 B 相比公布 A，将“动态闪烁/颜色/布尔显示”和“装配件中切换显示隐藏及线框消隐实现动态闪烁”等显示限定并入权利要求1，授权独权范围比公布文本更窄。

独立权利要求1要点：

1. 将待比对三维CAD软件建立的待比对模型和比对目标模型转换为统一STP格式的中间文件。
2. 将中间文件导入一致性比对工具。
3. 自动进行几何形状比对、MBD信息比对，得到比对测试结果。
4. 将比对结果按差异分别标记显示。
5. 几何形状差异通过动态闪烁、颜色标识或布尔运算结果显示。
6. 两个模型以装配方式装入一个装配件，通过切换显示/隐藏和线框消隐状态实现动态闪烁。

并列独立权利要求还包括系统权利要求6、电子设备权利要求7和计算机可读存储介质权利要求8，均围绕权利要求1至5的方法步骤进行模块化或载体化表达。

对我方方案A的影响：中等。它覆盖“STP统一格式 + 几何/MBD一致性比对 + 差异显示”，但没有看到“多层轻量摘要索引、先于BREP逐项比较筛除不相关特征、仿射判别、语义聚合”的完整组合。

对我方方案B的影响：低。未见永久命名集合运算和版本指纹筛选。

### 2.3 CN119312543B

证据来源：Google Patents 授权文本 HTML claims；并以本地 `E:\code\专利\已知专利\CN202411354990_FullTextImage.pdf` 的 CN119312543A 公布文本交叉核对。注意：授权 B 相比公布 A，将公布文本原权利要求2的“获取零件类型并按零件类型采用相应算法比较 BREP 数据”并入权利要求1，授权独权范围比公布文本更窄。

独立权利要求1要点：

1. 该案为“基于BREP的CAD模型对比方法、设备和存储介质”。
2. 方法包括：将两个目标CAD模型进行可视化比较。
3. 若可视化比较结果不一致，则确定两个目标CAD模型为不同模型。
4. 若可视化比较结果一致，则比较两个目标CAD模型的边界表示BREP数据。
5. 比较BREP数据包括：获取两个目标CAD模型的零件类型。
6. 根据两个目标CAD模型的零件类型，采用与该零件类型相应的算法比较两个目标CAD模型的BREP数据。
7. 若两个目标CAD模型的BREP数据比较结果一致，则确定两个目标CAD模型为相同模型。

并列独立权利要求还包括装置权利要求7、电子设备权利要求8和存储介质权利要求9，实质上复述或承载权利要求1至6的方法步骤。

对我方方案A的影响：中等。该案正好说明“BREP数据比较”已有公开。我方A调整后强调“在执行完整BREP实体逐项比较之前，先用轻量摘要筛除不相关特征或实体；必要时仅比较候选邻域局部BREP数据”，该方向与 CN119312543B 的“可视化比较后比较BREP数据”不同，建议继续把“先于完整BREP比较的轻量摘要预筛选”写成必要技术特征。

对我方方案B的影响：低。未见永久命名索引和集合运算。

### 2.4 CN111008429B

独立权利要求1要点：

1. 遍历原始CAD模型中的点、线、面。
2. 按给定精度要求对线、面进行分割。
3. 提取分割线段端点以及面片顶点数据，生成点云数据。
4. 将点云数据导入转换或重建的CAD模型中。
5. 按基本属性、线面邻接关系、边线点云、面点云格式存储为点云文件。
6. 确定特定线、面的归属：读取点云文件，获取邻接关系和点云数据；根据边线点到转换/重建CAD模型所有边线的最小距离确定对应边线；再通过邻接面点集距离确定对应邻接面。
7. 计算点云数据中的点到转换或重建CAD模型对应边、面的最小距离。
8. 根据距离输出原始CAD模型与转换或重建CAD模型的对比结果。

该授权文本共4项权利要求，仅权利要求1为独立权利要求。

对我方方案A的影响：中等。该案覆盖“异构CAD + 几何一致性 + 点云/距离对比”，但技术路径是点云分割与距离检测。我方A应避免将“点云化全模型后距离比较”作为核心，继续强调多层摘要、摘要索引、不相关特征筛除、语义摘要和关系摘要。

对我方方案B的影响：低。未见永久命名处理链。

### 2.5 US20180330042A1 / US10192023B2

独立权利要求1要点：

1. 系统包括显示器和处理器。
2. 接收第一CAD模型和第二CAD模型。
3. 比较第一模型元素的一组位置值数据与第二模型元素的一组位置值数据，以识别多个差异，其中第一组元素与第二组元素直接对应。
4. 生成包含差异的 discrepancy list。
5. 接收查看差异列表的输入，并显示包含差异列表的可视化结果。
6. 接收忽略某个差异的输入。
7. 接收验证某个差异的输入。
8. 更新可视化结果，保留已验证差异。

并列独立权利要求8为方法权利要求，核心是接收两个CAD模型、识别多个差异、生成差异列表、生成与差异关联的交互图标、接收用于验证差异保留的输入、生成排除未验证差异的更新差异列表并显示可视化结果。

并列独立权利要求15为非暂态计算机可读介质权利要求，核心是接收两个CAD模型、识别差异、生成差异列表，按照预编程过滤器移除某类差异，生成更新差异列表并显示。

对我方方案A的影响：中等偏低。该案偏差异列表和人工审查工作流，比较对象是“直接对应”的元素位置值，未见轻量摘要、多层语义/关系摘要、跨内核无永久命名、BREP预筛选。

对我方方案B的影响：中等偏低。它要求元素直接对应，但未见永久命名集合运算、版本指纹筛选、依赖传播和命名异常回退。

### 2.6 US7761265B2

独立权利要求1要点：

1. 在知识库中识别至少一个与查询模型具有预定相似度的solid model。
2. 比较查询模型的无向模型依赖图与知识库中某个solid model的无向模型依赖图。
3. 两个无向模型依赖图均由一组特征构造，特征包括形状、拓扑、形式、制造过程特征、装配/配合特征、影响工艺规划和加工操作选择的特征交互、夹具和制造操作特征空间等。
4. 使用 Ullmann 子图同构算法测试两个无向模型依赖图之间是否存在子图同构，并且基于节点 n-region density 初始化矩阵。
5. 若找到子图同构，识别具有子图同构的solid model。
6. 若未找到子图同构，识别具有足够大公共子图的模型。

并列独立权利要求15为知识库中多个 solid models 的分区方法，仍以无向模型依赖图、Ullmann 子图同构、n-region density 初始化及足够大公共子图为核心。权利要求12和21为记录有执行权利要求1或15方法的计算机可读指令的介质权利要求。

对我方方案A的影响：中等。该案覆盖“特征/拓扑/装配等多特征依赖图 + 图相似度/子图匹配”。我方A的关系摘要和语义摘要会受到该案启发式组合压力。差异点在于我方A不是知识库相似模型检索，不以Ullmann子图同构为核心，而是面向两个CAD模型差异快速筛选，强调跨内核、无永久命名、BREP前摘要预筛选、变换归一化和候选局部验证。

对我方方案B的影响：低到中等。该案有依赖图和特征相似度，但没有永久命名索引集合运算和版本指纹筛选。

### 2.7 US6445388B1

独立权利要求1要点：

1. 计算机图形系统，包括计算机、数据库和图像引擎。
2. 数据库存储三维图形图像表示，图像包括至少一个 loft feature。
3. 图像引擎包括 feature-based modeler，用于处理图像中的 loft feature。
4. loft feature 由一个或多个有序横截面生成，每个横截面包括一个或多个 segment。
5. 每个 segment 分配唯一 persistent name。
6. 为 segment 的 persistent name 创建一个或多个 cross-section matrix。
7. 通过 similarity analysis 和更新 cross-section matrix，使 segment 的唯一 persistent names 对 loft feature 的局部拓扑变化具有容错性。

并列独立权利要求18为计算机实现方法，权利要求35为承载逻辑的制品，均将权利要求1的系统处理流程改写为方法或介质/制品载体形式，核心仍是 loft feature 的 segment persistent name、cross-section matrix、similarity analysis 和矩阵更新。

对我方方案A的影响：低。该案是永久命名生成/维护，不是差异筛选。

对我方方案B的影响：中等。它强公开了“CAD实体永久命名 + 相似分析 + 拓扑变化下容错”。我方B不能声称永久命名本身新颖，必须把创新限定为“利用已有或可获取的永久命名索引进行差异对比”：集合运算、新增/删除/共有识别、版本指纹筛选、局部验证、依赖传播、语义聚合。

### 2.8 US7206661B2

独立权利要求1要点：

1. 在计算环境中接收 intermittent fillet weld bead 的连续路径P，该焊缝用于在制造中焊接多个部件。
2. 确定连续路径P的不变焊缝生成方向。
3. 将连续路径P细分为基本等长、相互间距基本相等的子路径。
4. 使用不变焊缝生成方向命名每个子路径，包括其边和顶点。

并列独立权利要求16为机器可读制品，其指令使装置执行接收连续路径、确定不变焊缝生成方向、细分子路径并命名子路径及其边和顶点，技术核心与权利要求1一致。

对我方方案A的影响：低。该案是特定焊缝路径的持久命名。

对我方方案B的影响：中等。它公开了特定CAD对象的永久命名机制和拓扑实体命名，但未公开以命名集合运算进行模型差异对比的完整链路。

## 3. 对方案A的权利要求级结论

方案A当前独立权利要求的关键要素为：

1. 不依赖两个CAD模型之间具有可比较永久命名。
2. 提取多层轻量化摘要，包括全局摘要、局部实体摘要、语义摘要、关系摘要中的至少两种。
3. 基于摘要确定变换关系，并执行位姿、尺度或仿射归一化，或记录全局差异。
4. 在完整BREP实体逐项比较之前，基于归一化后的摘要建立摘要索引。
5. 通过摘要索引筛除与目标特征或目标实体不满足候选关系的不相关特征或实体。
6. 对候选匹配实体执行局部验证。
7. 将实体级差异聚合为设计语义级差异。

### 3.1 主要新颖性压力

最大压力仍来自 CN116433837B。它覆盖“CAD差异分析、图匹配、刚体变换、逐层实体差异判断”。如果方案A被解释为泛泛“摘要/图匹配 + 变换 + 分层比较”，会有明显重合。

CN119312543B 对“BREP对比”形成压力，因此方案A应继续避免把完整BREP比较写成核心步骤。

US7761265B2 对“特征/依赖图/子图相似性”形成创造性压力，因此方案A中的关系摘要不宜写成传统子图同构检索，而应与“BREP前预筛选”和“候选局部验证”绑定。

### 3.2 推荐保留/加强的区别特征

建议方案A独权继续保留以下必要特征：

1. “不依赖可比较永久命名”。
2. “在执行完整BREP实体逐项比较之前”。
3. “基于轻量化多层摘要建立摘要索引”。
4. “筛除不满足候选关系的不相关特征或实体”。
5. “必要时仅比较候选实体邻域的局部BREP数据”。
6. “仿射变换不可归一化时作为全局差异输出”。
7. “实体级差异聚合为设计语义级差异”。

这组组合在本次8件独立权利要求中未见单件完整覆盖。

## 4. 对方案B的权利要求级结论

方案B当前独立权利要求的关键要素为：

1. 获取第一/第二CAD模型的永久命名实体索引。
2. 基于永久命名标识执行集合运算，确定新增、删除、共有实体。
3. 对共有实体比较实体摘要或版本指纹，确定候选变化实体。
4. 对候选变化实体执行局部验证。
5. 基于实体依赖关系将实体级差异聚合为设计语义级差异。

### 4.1 主要新颖性压力

US6445388B1 和 US7206661B2 公开永久命名生成/维护机制，对“永久命名”作为基础技术构成强现有技术。

US20180330042A1 公开两个CAD模型差异识别、差异列表和可视化审查，对“CAD差异列表输出”构成背景。

US7761265B2 公开模型依赖图和特征相似度，对“依赖关系/语义聚合”的泛化表述有创造性压力。

### 4.2 推荐保留/加强的区别特征

建议方案B独权不要保护“如何生成永久命名”，而保护以下处理流水线：

1. 将两个模型的永久命名实体索引视为已存在或可获取。
2. 对永久命名标识做集合运算，直接得到新增、删除、共有实体。
3. 对共有实体通过版本指纹/实体摘要筛出候选变化实体。
4. 仅对候选变化实体局部验证。
5. 基于实体依赖关系执行语义聚合和影响范围传播。
6. 从属项保护命名冲突/命名失效检测和摘要辅助匹配。

这组组合在本次8件独立权利要求中未见单件完整覆盖。

## 5. 总体判断

1. 方案A与 CN116433837B 最接近，但通过“跨CAD内核、无可比永久命名、BREP前轻量摘要预筛选、不相关特征筛除、候选局部BREP验证、语义聚合”可以形成区别。
2. 方案A与 CN119312543B 的关系应被写成“避开完整BREP全量比较”：CN119是可视化比较后进入BREP数据比较，我方A是在BREP逐项比较之前用摘要排除不相关特征。
3. 方案B与 US6445388B1、US7206661B2 的区别在于：对方保护永久命名机制，我方保护基于永久命名索引的差异对比流水线。
4. 方案B与 US20180330042A1 的区别在于：对方是位置值直接对应比较 + discrepancy list 审查，我方是命名集合运算 + 指纹筛选 + 局部验证 + 语义聚合。
5. 两案均建议保留，且应继续保持保护侧重点分离：方案A主打跨内核/无永久命名/摘要预筛选；方案B主打同命名域/永久命名索引/集合运算加速。
