# 基于轻量化多层摘要与变换归一化的CAD模型差异对比方法及系统

## 1. 发明名称

一种基于轻量化多层摘要与变换归一化的CAD模型差异对比方法、系统、电子设备及存储介质。

## 2. 技术领域

本发明涉及计算机辅助设计、三维模型处理、CAD模型版本管理和几何差异分析领域，尤其涉及一种不依赖特定CAD内核永久命名规则的模型差异对比方法及系统。

## 3. 背景技术

在CAD设计、制造审查、版本管理、供应商模型比对和参数化系列件管理中，经常需要比较两个CAD模型之间的差异。现有方法通常包括基于几何实体的全量匹配、基于拓扑关系的图匹配、基于模型树或特征树的比较，以及基于CAD永久命名的实体对应关系比较。

永久命名能够在同一CAD内核、同一建模系统或同一模型版本链中稳定追踪面、边、体、特征等对象，因而可以显著降低差异对比的搜索范围。但在跨CAD内核、跨建模系统、跨文件格式或供应商模型交换场景中，不同系统生成的永久命名规则并不一致，永久命名信息往往不可比较，甚至在中间格式转换后丢失。因此，若差异对比方法将永久命名作为必要前提，其适用范围会受到明显限制。

另一方面，直接对两个模型中的几何或拓扑实体进行两两匹配，容易产生接近平方级的计算开销。对于包含大量面、边、特征或装配约束的复杂模型，全量匹配不仅耗时，而且容易受到模型位姿、坐标系、单位缩放、全局仿射变换和局部建模容差的影响，导致误判或漏判。

因此，需要一种更轻量、更通用的CAD模型差异对比方案，使其能够在不依赖统一永久命名体系的情况下，快速生成候选匹配关系，并正确处理位姿变化、相似变换和仿射变换对差异识别的影响。

## 4. 发明目的

本发明的目的在于提供一种基于轻量化多层摘要与变换归一化的CAD模型差异对比方法及系统，用以解决以下问题：

1. 不同CAD内核或不同建模系统生成的永久命名不可直接比较，导致基于永久命名的差异对比方法难以跨系统使用。
2. 传统几何实体全量匹配计算量大，复杂度高，不适合大规模模型或频繁版本比较。
3. 模型的平移、旋转、装配位姿、单位缩放、非均匀缩放或仿射变换容易影响差异识别结果。
4. 仅输出底层几何差异难以表达设计意图，需要将面、边、体等拓扑变化聚合为孔、倒角、阵列、槽、筋、装配约束等语义级变化。

## 5. 总体技术方案

本发明对待比较的第一CAD模型和第二CAD模型分别提取多层轻量化摘要，并基于所述摘要进行变换判别、位姿归一化、候选匹配生成、局部精确验证和语义差异聚合。

所述轻量化摘要不依赖特定CAD内核的永久命名，而是从模型的几何、拓扑、语义和关系结构中提取可快速计算、可索引、可比较的描述信息。系统首先基于全局摘要估计两个模型之间的整体变换关系，包括刚体变换、相似变换或仿射变换；再在归一化空间中比较局部实体摘要，生成候选匹配集合；随后仅对候选实体执行较高成本的几何、拓扑或语义验证；最后将实体级差异聚合为设计语义级差异。

当两个模型存在可比较的永久命名信息时，永久命名可作为候选匹配约束、置信度增强项或索引加速项；当永久命名不存在、丢失或不可比较时，系统仍可依靠轻量化摘要完成差异对比。

## 6. 轻量化多层摘要

### 6.1 全局摘要

全局摘要用于快速判断两个模型的整体相似程度，并为位姿或仿射归一化提供初始约束。全局摘要可以包括：

1. 模型体积、表面积、包围盒尺寸、包围盒长宽高比例。
2. 质心、惯性矩、主惯性轴、主方向分布。
3. 面数量、边数量、体数量、壳数量、连通分量数量。
4. 平面、圆柱面、圆锥面、球面、自由曲面等曲面类型分布。
5. 直线边、圆弧边、样条边等曲线类型分布。
6. 全局拓扑邻接统计和全局语义结构统计。

### 6.2 局部实体摘要

局部实体摘要用于描述单个面、边、体或局部子结构，并用于生成候选匹配实体。局部实体摘要可以包括：

1. 面摘要：面积、曲面类型、法向方向类别、曲率范围、边界环数量、内环数量、相邻面类型分布。
2. 边摘要：长度、曲线类型、端点邻接关系、相邻面夹角、是否为凸边或凹边。
3. 体摘要：体积、表面积、局部包围盒、连通性、相邻特征分布。
4. 局部子图摘要：以实体为中心的若干阶邻接关系、面-边-面结构模式、局部拓扑哈希。

### 6.3 语义摘要

语义摘要用于表示设计意图相关的结构。系统可以基于几何和拓扑规则识别孔、倒角、圆角、阵列、槽、筋、薄壁、凸台、装配约束等结构，并记录其轻量参数。例如：

1. 孔结构的轴线方向、直径、深度、贯通状态和相邻面集合。
2. 倒角或圆角的半径、长度范围、作用边集合和相邻面集合。
3. 阵列结构的实例数量、方向、间距和基准元素摘要。
4. 装配约束的约束类型、参与实体摘要、自由度影响和约束方向。

### 6.4 关系摘要

关系摘要用于表达实体之间的拓扑关系、生成关系、引用关系和装配关系。关系摘要可以表示为实体关系图，其中节点为面、边、体、特征、参数或约束，边表示相邻、包含、生成、依赖、引用或约束关系。系统可对局部关系图生成图哈希或子图指纹，用于提高候选匹配的判别能力。

## 7. 变换判别与归一化

### 7.1 位姿变化处理

对于平移、旋转或装配坐标变化，系统不应将其识别为模型几何差异。为此，系统可以采用下列方式之一或组合：

1. 使用面积、体积、长度、夹角、曲率、邻接关系等平移和旋转不变量构造摘要。
2. 基于质心、主惯性轴、主方向或锚点结构估计初始刚体变换。
3. 基于候选匹配实体执行RANSAC、ICP或其他配准方法，得到刚体变换。
4. 将第二模型变换到第一模型的归一化坐标系后再执行局部差异验证。

### 7.2 相似变换处理

对于单位变化或整体等比例缩放，系统可以估计统一尺度因子，并判断该尺度因子是否满足预设容差或单位换算规则。若满足，则在尺度归一化后比较模型差异；若不满足，则将整体尺度变化作为全局差异输出。

### 7.3 仿射变换处理

对于非均匀缩放、剪切或其他仿射变换，系统先估计两个模型之间的全局仿射矩阵，并判断该矩阵是否可解释为坐标系变换、单位变换、导入导出变换或真实设计变更。

若仿射变换满足预设容差、业务规则或数据来源规则，系统可在仿射归一化空间中继续比较局部差异。若仿射变换不满足上述条件，系统将其作为全局形变差异输出，并继续识别局部新增、删除和修改实体。

### 7.4 变换对摘要的影响

系统可以根据变换类型选择不同的摘要比较策略：

1. 对刚体变换，优先使用距离、面积、体积、夹角和拓扑邻接等刚体不变量。
2. 对相似变换，使用归一化长度、面积比例、体积比例和拓扑关系。
3. 对仿射变换，使用拓扑关系、曲面类型变化、邻接模式以及经仿射校正后的几何摘要。
4. 对无法归一化的变换，将全局变换本身作为差异结果的一部分。

## 8. 系统模块

### 8.1 模型解析模块

用于读取第一CAD模型和第二CAD模型，解析其中的几何、拓扑、特征、参数和装配约束信息。

### 8.2 轻量化摘要提取模块

用于分别提取全局摘要、局部实体摘要、语义摘要和关系摘要，并将摘要组织为可索引的数据结构。

### 8.3 变换判别模块

用于根据全局摘要、锚点实体、候选对应关系或配准算法，估计两个模型之间的刚体变换、相似变换或仿射变换，并判断该变换应被归一化还是输出为差异。

### 8.4 摘要索引与候选匹配模块

用于基于轻量化摘要建立哈希索引、分桶索引、近似最近邻索引或图摘要索引，并生成实体候选匹配集合。

### 8.5 局部验证模块

用于对候选匹配实体执行更精确的几何、拓扑、参数或语义验证，确认实体是否保持不变、发生修改、新增或删除。

### 8.6 语义差异聚合模块

用于根据实体关系图和语义摘要，将底层实体差异聚合为设计语义级差异，例如孔直径变化、倒角半径变化、阵列数量变化、槽位置变化、装配约束目标变化等。

### 8.7 永久命名辅助模块

用于在两个模型存在可比较永久命名信息时，将永久命名作为候选匹配约束、置信度增强信息或快速索引；当永久命名不存在或不可比较时，该模块不作为必要步骤。

### 8.8 差异输出模块

用于输出结构化差异结果，包括实体级差异、语义级差异、全局变换差异、影响范围、置信度、变化前后摘要，以及可用于CAD系统高亮显示的定位信息。

## 9. 方法流程

1. 获取第一CAD模型和第二CAD模型。
2. 分别解析两个模型的几何、拓扑、语义和关系信息。
3. 分别提取两个模型的全局摘要、局部实体摘要、语义摘要和关系摘要。
4. 根据全局摘要和候选锚点估计两个模型之间的变换关系。
5. 判断所述变换关系属于刚体变换、相似变换、仿射变换或不可归一化变换。
6. 对可归一化的变换执行位姿、尺度或仿射归一化；对不可归一化的变换记录为全局差异。
7. 基于归一化后的摘要建立索引，并生成候选匹配实体集合。
8. 对候选匹配实体执行局部几何、拓扑、参数或语义验证。
9. 根据验证结果识别新增实体、删除实体、修改实体和保持不变实体。
10. 基于实体关系图和语义摘要，将实体级差异聚合为设计语义级差异。
11. 输出包含拓扑实体级差异、设计语义级差异和全局变换差异的模型差异结果。

## 10. 复杂度优势

传统方法若对两个模型的实体集合进行全量几何匹配或拓扑匹配，复杂度容易接近 O(n^2)，其中 n 为模型实体数量。对于复杂模型，该计算量会随着面、边和特征数量增长而快速增加。

本发明通过轻量化摘要将大部分实体比较转化为索引检索和候选筛选：

1. 摘要提取复杂度通常为 O(n)。
2. 基于哈希、分桶或近似索引的候选生成复杂度可接近 O(n) 或 O(n log n)。
3. 局部精确验证仅作用于候选集合，复杂度为 O(k) 或 O(k log n)，其中 k 为候选变化实体数量，通常远小于 n。

因此，本发明能够将主要差异对比过程从接近平方级的全量匹配降低为接近线性或准线性的候选筛选加局部验证过程。对于同一模型的不同版本或同族相似模型，由于大部分实体保持不变，k 通常明显小于 n，复杂度优势更加显著。

当存在可比较的永久命名信息时，系统还可以直接利用永久命名缩小候选集合，从而进一步降低候选生成和验证成本。但永久命名并非本发明的必要前提。

## 11. 建议权利要求布局

### 11.1 方法主权利要求

一种CAD模型差异对比方法，包括：

1. 获取第一CAD模型和第二CAD模型；
2. 分别提取所述第一CAD模型和第二CAD模型的多层轻量化摘要，所述多层轻量化摘要包括全局摘要、局部实体摘要、语义摘要和关系摘要中的至少两种；
3. 基于所述多层轻量化摘要确定所述第一CAD模型和第二CAD模型之间的变换关系；
4. 根据所述变换关系对至少一个模型执行位姿归一化、尺度归一化或仿射归一化，或者将所述变换关系记录为全局差异；
5. 基于归一化后的多层轻量化摘要生成候选匹配实体集合；
6. 对所述候选匹配实体集合执行局部几何、拓扑、参数或语义验证；
7. 根据验证结果确定新增实体、删除实体、修改实体和保持不变实体；
8. 基于实体关系和语义摘要，将实体级差异聚合为设计语义级差异；
9. 输出包含实体级差异、设计语义级差异和全局变换差异中的至少一种的差异结果。

### 11.2 系统权利要求

一种CAD模型差异对比系统，包括：

1. 模型解析模块，用于解析第一CAD模型和第二CAD模型；
2. 轻量化摘要提取模块，用于提取全局摘要、局部实体摘要、语义摘要和关系摘要；
3. 变换判别模块，用于确定两个模型之间的刚体变换、相似变换或仿射变换；
4. 摘要索引与候选匹配模块，用于基于轻量化摘要生成候选匹配实体集合；
5. 局部验证模块，用于验证候选匹配实体的几何、拓扑、参数或语义差异；
6. 语义差异聚合模块，用于将实体级差异聚合为设计语义级差异；
7. 差异输出模块，用于输出差异结果；
8. 永久命名辅助模块，用于在存在可比较永久命名信息时利用永久命名辅助候选匹配。

### 11.3 从属权利要求方向

1. 所述全局摘要包括体积、表面积、包围盒比例、质心、惯性矩、主惯性轴、曲面类型分布和拓扑实体数量中的一种或多种。
2. 所述局部实体摘要包括面积、长度、曲率、曲面类型、曲线类型、相邻实体类型、边界环数量和局部拓扑哈希中的一种或多种。
3. 所述语义摘要包括孔、倒角、圆角、阵列、槽、筋、薄壁、凸台或装配约束的结构标签和参数摘要。
4. 所述关系摘要包括面-边-面邻接关系、特征依赖关系、参数引用关系和装配约束关系中的一种或多种。
5. 所述变换判别模块基于质心、主惯性轴、锚点实体、RANSAC配准或ICP配准确定模型之间的变换关系。
6. 当变换关系为刚体变换时，系统基于距离、面积、体积、夹角、曲率和拓扑邻接中的至少一种不变量进行比较。
7. 当变换关系为相似变换时，系统基于尺度归一化后的摘要进行比较。
8. 当变换关系为仿射变换时，系统判断所述仿射变换是否满足预设容差或业务规则；若满足，则执行仿射归一化后比较；若不满足，则将其作为全局形变差异输出。
9. 当第一CAD模型和第二CAD模型包含可比较的永久命名信息时，系统利用永久命名作为候选匹配约束或置信度增强项。
10. 所述差异结果包括可用于CAD系统高亮显示的实体定位信息。

## 12. 创新点总结

1. 将CAD差异对比的主依赖从永久命名转移到跨内核可用的轻量化多层摘要，扩大适用范围。
2. 通过全局摘要、局部实体摘要、语义摘要和关系摘要协同生成候选匹配集合，降低全量几何匹配成本。
3. 将位姿变化、相似变换和仿射变换纳入差异对比流程，避免将坐标变换误判为设计差异。
4. 对不可归一化或不应归一化的仿射变换，将其作为全局形变差异输出。
5. 通过局部验证和语义聚合，将底层实体变化转化为设计意图层面的差异结果。
6. 将永久命名设计为可选辅助模块，而非必要前提，从而兼容同内核版本对比和跨内核模型对比。
