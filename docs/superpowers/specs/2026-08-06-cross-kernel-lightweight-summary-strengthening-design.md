# 跨 CAD 内核轻量摘要差异对比强化设计

## 1. 发明核心

本方案解决的核心技术问题是：在第一 CAD 模型和第二 CAD 模型来自不同 CAD 内核、不同文件格式或不同转换链路，且缺少可比较永久命名的情况下，如何减少完整 BREP 数据读取和实体两两比较，同时得到可定位的实体级差异及设计语义级差异。

本方案不把“先粗略比较、再比较 BREP”作为发明核心，而以以下不可分割的处理闭环作为主线：

1. 在不对两个模型执行完整 BREP 实体逐项比较的初始阶段，提取可索引的多层轻量摘要。
2. 估计并验证一个或多个跨内核变换假设，将坐标、位姿和单位变化与设计变化分离。
3. 通过至少两个顺序摘要闸门输出实体级候选关系和排除关系，构造稀疏候选关系集合。
4. 对候选关系执行互斥约束、候选裕量和局部关系一致性消歧。
5. 仅对消歧后的候选实体及其有限邻域按需读取局部 BREP 数据并精确验证。
6. 形成一对一实体对应关系以及经验证的一对多拓扑分裂、多对一拓扑合并关系。
7. 在消费全部有效关系端点后计算共有、修改、新增和删除，并聚合为可定位的设计语义级变化。

## 2. 与主要现有技术的边界

### 2.1 与 CN119312543A 的边界

CN119312543A 以“可视化比较不一致则判定模型不同；可视化一致则进入 BREP 比较；BREP 一致则判定模型相同”为主线，并进一步按零件类型、体、面、边等层级比较 BREP。

本方案不采用模型级粗比较结果作为终止性的“相同/不同”结论，而将全局、局部和关系摘要转化为实体级候选关系、排除关系和搜索范围约束；后续不进行全模型或全部分层 BREP 比较，只读取候选实体邻域的局部 BREP，并输出具体的对应、修改、新增、删除、分裂、合并和语义变化。

### 2.2 与关键点或全模型图匹配路线的边界

本方案的候选关系不是通过 NURBS 控制点关键点匹配或全模型图同构直接生成最终实体对应。关系摘要仅作为候选闸门和局部一致性条件，摘要闸门输出仍须经过互斥消歧和局部验证。

### 2.3 与点云全量距离比较路线的边界

轻量网格顶点、采样点或凸包点仅用于形成统计摘要和候选排除条件，不要求把两个完整模型点云化后执行全量点到点或点到面距离比较。

## 3. 数据模型和术语

### 3.1 模型与实体全集

第一 CAD 模型记为 `M_A`，第二 CAD 模型记为 `M_B`。按选定比较层级分别形成可审计实体集合：

`U_A^l={a_1,...,a_n}`，`U_B^l={b_1,...,b_m}`。

其中 `l` 表示装配发生、零部件、体、壳、面、边、特征或语义结构层级。同一次实体关系计算只在拓扑维度或语义类型相容的集合之间进行；不同维度对象不进入同一个一对一候选池。

可审计实体排除纯显示对象、无几何意义的辅助对象、读取失败对象和明确不在业务比较范围内的对象。被排除对象及排除原因进入证据记录。

### 3.2 模型内定位符

本方案不要求跨模型稳定名称，但为每个模型内实体保留可用于回查和高亮的瞬时定位符。定位符可以包括：

- 装配发生路径和零部件路径；
- 当前文件或当前模型会话中的实体句柄、记录偏移或局部序号；
- 轻量网格片段标识；
- 包围盒、质心、主方向和局部几何锚点；
- 局部邻接摘要或局部拓扑签名。

差异结果同时保存模型 A 定位符和模型 B 定位符，不将瞬时定位符宣称为永久命名。

### 3.3 多层轻量摘要

多层轻量摘要包括以下至少两类：

1. 全局摘要 `G_X`：体积、表面积、包围盒、质心、惯性矩、主轴、实体数量、曲面类型分布、曲线类型分布、轻量网格统计和全局凸包摘要。
2. 局部实体摘要 `L_X(e)`：实体维度、支承曲面或曲线类别、面积、长度、曲率区间、边界环数量、内环数量、相邻实体类型分布、局部包围盒和局部凸包摘要。
3. 语义摘要 `S_X(e)`：孔、倒角、圆角、槽、筋、凸台、薄壁、阵列、草图约束或装配约束的类型、参数和作用范围。
4. 关系摘要 `H_X(e)`：预定阶数邻域内的面-边-面邻接统计、包含关系、局部拓扑角色、特征依赖、参数引用和装配约束关系。

初始筛选阶段的摘要至少部分来源于模型元数据、轻量网格、实体属性、拓扑统计或设计语义识别结果，而不要求将两个模型的全部 BREP 实体逐项载入并两两比较。

## 4. 总体处理流程

### S100：输入检查和比较范围确定

1. 读取模型来源、CAD 内核、文件格式、单位、坐标系、装配层级和可用数据族。
2. 判断永久命名是否缺失、不可比较或不足以覆盖当前比较层级；该判断只确定技术入口，不生成永久命名。
3. 按比较层级形成 `U_A^l`、`U_B^l`，记录排除对象和数据缺失状态。
4. 统一数值单位、角度表达、法向方向约定和基础容差。

### S200：轻量摘要提取

1. 提取 `G_A`、`G_B`。
2. 对 `U_A^l`、`U_B^l` 中每个对象提取 `L_X(e)`。
3. 在可识别时提取 `S_X(e)` 和 `H_X(e)`；缺失的摘要分量被标记为不可用，不按零差异处理。
4. 为摘要生成数据来源标识和计算版本，以支持证据追溯。

### S300：变换假设生成和归一化

1. 根据质心、惯性轴、包围盒比例、语义锚点和高区分度局部摘要生成刚体、相似或仿射候选变换 `T_1,...,T_p`。
2. 对存在对称性、主轴符号翻转或等特征值的模型保留多个候选变换，而不是固定采用单一主轴方向。
3. 利用锚点投票、候选摘要残差和局部关系残差计算变换评分 `Q_T`。
4. 对满足单位换算、坐标变换或已知转换规则且残差低于阈值的变换执行归一化。
5. 对不能解释的非均匀缩放、剪切或高残差变换记录为全局形变差异；记录全局差异后仍可继续局部候选筛选，不直接终止为“模型不同”。

### S400：顺序摘要闸门和稀疏候选关系

#### S410：全局摘要闸门

全局摘要闸门不直接输出最终相同或不同结论，而输出以下至少一种：

- 可用变换假设；
- 空间搜索区域、尺度区间或方向区间；
- 模型级或零部件级全局差异；
- 后续候选搜索约束。

#### S420：局部实体摘要闸门

对每个目标实体只在索引命中的小范围对象中生成候选。硬排除条件至少包括拓扑维度不相容、实体类别不相容或空间区域不可能重叠。软条件包括面积、长度、曲率、边界环、局部包络和语义参数差异。

局部闸门输出候选三元组 `(a,b,s_local)` 或排除记录 `(a,b,reason)`。

#### S430：关系摘要闸门

对局部候选比较预定阶数邻域的拓扑角色、相邻实体类型多重集、包含关系和语义关系。关系不相容时删除候选边；关系相容时提高候选置信度。

闸门完成后形成稀疏候选关系集合：

`C={(a,b,s_ab)|a in U_A^l,b in U_B^l}`，且 `|C|` 显著小于 `|U_A^l|*|U_B^l|`。

### S500：候选评分和互斥消歧

#### S510：基础差异量

容差归一化数值差异：

`d_num(x,y)=clip((|x-y|-eps_abs)/(eps_abs+eps_rel*max(|x|,|y|)),0,1)`。

集合或邻接多重集差异可以采用 Jaccard 差异：

`d_set(X,Y)=1-|X intersect Y|/max(|X union Y|,1)`。

方向差异采用归一化夹角；类别差异采用零一差异。实体维度或硬类型不相容时直接排除，不进入加权平均。

#### S520：候选相似度

对实际可用摘要维度集合 `J(a,b)` 计算：

`S(a,b)=sum(alpha_i*(1-d_i))/sum(alpha_i), i in J(a,b)`。

缺失摘要分量不进入分子和分母。若全部判别分量均缺失，则不直接接受候选，而进入低信息待验证或待复核状态。

#### S530：候选裕量和互斥约束

对实体 `a` 的最佳和次佳候选分数分别记为 `S_1(a)`、`S_2(a)`。高置信度一对一候选至少满足：

- `S_1(a)>=tau_match`；
- `S_1(a)-S_2(a)>=delta_margin`；
- 候选在反方向检索中同样满足预定排名条件；
- 实体尚未被另一个一对一关系占用。

其余竞争候选可在局部分块内通过最大权匹配、稳定匹配或其他满足互斥条件的求解方法消歧。算法名称作为实施方式，不限定为唯一实现。

### S600：按需局部 BREP 验证

局部验证仅加载：

- 被选择的候选实体；
- 候选实体的预定阶数邻域；
- 候选实体所属特征或语义结构；
- 验证分裂、合并所需的相邻实体组。

对于面实体，验证项目可包括支承曲面类型和参数、修剪边界、边界环、面积、法向、曲率、相邻边和相邻面；对于边实体，可包括支承曲线、端点、长度、方向、相邻面和凸凹角色；对于体或壳，可包括连通性、边界面组成和局部体积。

局部验证输出验证状态、验证差异、所读取的 BREP 范围和证据定位符。

### S700：对应关系和拓扑谱系关系

#### S710：一对一关系

通过候选消歧和局部验证的一对一关系构成 `R_11`。一对一关系表示同一设计实体或同一可追踪实体在两个模型中的对应，不等价于保持不变。

#### S720：拓扑分裂

对于一个旧实体对应多个新实体的候选组，仅在以下条件中的至少两项满足时形成 `R_1m`：

- 子实体与旧实体具有相同或相容的支承几何；
- 子实体修剪域的并集覆盖旧实体修剪域至预定容差；
- 子实体面积或长度之和与旧实体相符；
- 子实体之间存在新增拓扑分界；
- 子实体外部邻接关系与旧实体外部邻接关系相容。

例如，一个平面面因新增拓扑分界边而被划分为两个具有相同支承平面的修剪面，属于一对多拓扑分裂。

#### S730：拓扑合并

对于多个旧实体对应一个新实体的候选组，以反向的支承几何、修剪域覆盖、度量守恒和外部邻接条件验证 `R_m1`。例如，相邻共面面之间的分界边被移除后形成一个合并面。

同一模型快照内一个标识关联多个面不作为拓扑分裂的表达；本方案的分裂和合并是跨版本实体谱系关系。

### S800：最终差异集合闭包

定义 `R=R_11 union R_1m union R_m1`。

严格共有实体关系为：

`COMMON=R_11`。

可追踪共有范围还包括 `R_1m` 和 `R_m1` 的关系端点，但分裂或合并实体不重复计入严格一对一共有数量。

删除实体集合：

`DEL=U_A^l - dom(R)`。

新增实体集合：

`ADD=U_B^l - ran(R)`。

只有在全部经验证关系端点被消费后才计算 `DEL` 和 `ADD`，从而避免把分裂、合并或低置信度待验证对象误判为简单新增或删除。

### S810：一对一实体的具体差异

对 `(a,b) in R_11` 计算：

`D(a,b)=sum(w_i*d_i)/sum(w_i), i in J_verify(a,b)`。

其中差异分量包括几何差异、拓扑差异、参数差异、语义差异和关系差异。缺失维度重新归一化权重。

- `D<=tau_same` 且无硬冲突：保持不变；
- `D>tau_same` 且身份或拓扑角色保持可追踪：修改；
- 若存在普通模型内名称或业务标签变化，可附加重标识标签，但不以永久名称作为必要条件。

最终主分类至少包括保持不变、修改、分裂、合并、新增、删除和待复核。每个实体在同一比较层级只进入一个最终主分类；复合工程语义作为副标签输出。

### S900：设计语义聚合和定位输出

1. 将实体差异沿所属结构、邻接和参数关系聚类。
2. 根据语义摘要和结构模板识别孔径变化、孔位置变化、倒角新增、圆角删除、槽深变化、阵列数量变化、装配约束变化等语义事件。
3. 一个语义事件保存其成员实体关系、验证证据、置信度和影响范围。
4. 输出模型 A、模型 B 双侧定位符，使应用能够在各自 CAD 查看器中高亮对应实体或变化区域。

## 5. 场景处理矩阵

| 场景 | 检测信号 | 处理策略 | 输出 |
|---|---|---|---|
| 同一零件仅有刚体位姿变化 | 体积、面积和拓扑统计接近，刚体残差低 | 执行刚体归一化，继续摘要闸门 | 位姿已归一化，不报告设计修改 |
| 毫米与英寸单位变化 | 单一尺度因子接近预设单位换算比 | 执行尺度归一化并换算容差 | 单位变化证据及局部真实差异 |
| 无法解释的非均匀缩放或剪切 | 仿射残差低但不满足已知转换规则 | 记录全局形变，同时继续局部匹配 | 全局形变加局部差异 |
| 对称模型导致主轴歧义 | 主惯性矩等值或主轴候选评分接近 | 保留多个变换假设，以锚点和关系残差消歧 | 采用的变换及候选证据；无法消歧则待复核 |
| 跨内核拓扑细分 | 支承几何相容但一个旧修剪域对应多个新修剪域 | 验证覆盖、度量守恒和外部邻接，建立 `R_1m` | 拓扑分裂，不重复报新增 |
| 跨内核拓扑合并/几何修复 | 多个旧实体共同覆盖一个新实体 | 反向验证并建立 `R_m1` | 拓扑合并，不重复报删除 |
| 局部倒角或孔发生改变 | 全局摘要接近，局部几何和语义摘要变化 | 保留候选关系，局部 BREP 验证参数和边界 | 修改实体及孔/倒角语义变化 |
| 新增局部特征 | 新模型实体无有效对应，邻域形成新语义结构 | 完成全部关系验证后列入 `ADD`，再聚合 | 新增实体和新增特征 |
| 删除局部特征 | 旧模型实体无有效对应 | 完成全部关系验证后列入 `DEL`，再聚合 | 删除实体和删除特征 |
| 装配体包含重复实例 | 多个发生具有相同零部件摘要 | 以发生路径、变换和局部约束分块匹配 | 零部件复用与发生级差异分离 |
| 轻量数据缺失部分语义或关系摘要 | 某些摘要分量不可用 | 对可用维度重新归一化；降低置信度并扩大局部验证 | 有限置信度差异或待复核 |
| BREP 局部读取失败 | 候选定位符可用但精确数据不可读 | 保留候选和摘要证据，不输出确定性新增/删除 | 局部验证失败和待复核状态 |
| 两模型整体差异很大 | 全局摘要差异显著 | 输出全局差异并以零部件/空间分区继续筛选；业务允许时提前终止 | 全局差异、已确认局部差异或不可比较原因 |

## 6. 可复算实施例

选择面、边和语义特征的预定比较层级后，模型 A 含 100 个可审计实体，模型 B 含 105 个可审计实体。若执行全量两两比较，需要考察 10,500 个实体对。

1. 全局摘要闸门输出变换假设和空间搜索约束。
2. 局部摘要索引生成 310 个候选关系。
3. 关系摘要闸门将候选缩减为 126 个，候选比例为 `126/10500=1.2%`。
4. 互斥消歧和局部 BREP 验证得到 94 个一对一关系、1 个一对多分裂关系和1个多对一合并关系。
5. 分裂关系覆盖模型 A 的1个实体和模型 B 的2个实体；合并关系覆盖模型 A 的2个实体和模型 B 的1个实体。
6. 最终关系端点分别覆盖两个模型各97个实体，因此 `|DEL|=100-97=3`，`|ADD|=105-97=8`。
7. 94 个一对一关系进一步分为86个保持不变和8个修改；分裂、合并、新增和删除不与上述分类重复。

实施例应同时记录实际读取的局部 BREP 实体数量、候选关系数量、验证失败数量和待复核数量。若有真实产品测试数据，应以真实测量结果替换示例性的候选数量，不虚构运行时间或准确率。

## 7. 权利要求布局

### 7.1 方法独立权利要求必要技术特征

1. 确定待比较模型缺少可比较永久命名或永久命名不可信。
2. 在不执行完整 BREP 实体逐项比较的初始阶段提取至少两类轻量摘要。
3. 基于摘要生成并验证变换假设，执行归一化或记录全局差异。
4. 在完整 BREP 比较之前依次执行至少两个摘要闸门，输出实体候选关系和排除关系。
5. 对候选关系执行互斥约束和候选冲突消解。
6. 仅对消歧后的候选实体及其局部邻域读取或比较局部 BREP。
7. 形成一对一对应以及经验证的分裂或合并关系，并在关系闭包后计算共有、新增、删除和修改。
8. 将实体级差异聚合为设计语义差异并输出双侧定位信息。

### 7.2 从属权利要求方向

- 摘要数据来源和摘要具体组成；
- 多变换假设、对称性处理和残差选择；
- 三类摘要闸门的输入、规则和输出；
- 容差归一化差异、候选相似度和候选裕量；
- 双向最佳、局部最大权匹配或其他互斥求解；
- 面、边、体的局部 BREP 验证范围；
- 拓扑分裂和合并的覆盖、守恒及邻接条件；
- 差异集合闭包和互斥分类；
- 装配发生级匹配和重复实例处理；
- 语义聚合、影响范围和双侧定位符；
- 候选压缩率、BREP 读取比例及证据记录。

### 7.3 并列独立权利要求

保留系统、电子设备和计算机可读存储介质权利要求。系统模块与方法闭环一一对应，避免系统权利要求退化为泛化的软件模块列表。

## 8. 验证与交付标准

1. 摘要、独立权利要求、说明书技术方案和实施例使用相同的步骤顺序与术语。
2. 说明书明确区分候选相似度和验证后差异分数。
3. 说明书明确区分一对一实体对应与一对多/多对一拓扑谱系。
4. 新增和删除只在全部有效关系端点被消费后计算。
5. 所有公式定义分子、分母、空集合和缺失维度处理。
6. 至少包含一个可复算数量实施例和覆盖主要异常场景的处理矩阵。
7. 申请 DOCX 和技术交底书均包含核心闭环，附图与正文一致。
8. DOCX 生成后逐页渲染检查，无裁切、重叠、乱码、失配标题或缺失附图。
