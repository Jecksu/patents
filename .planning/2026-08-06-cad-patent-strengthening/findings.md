## Identified specification gaps

- 永久命名稿目前用集合差直接给出“仅第一模型=删除、仅第二模型=新增、两边同名=共有”，但没有先把重复名称、空名称、无效名称和一对多/多对一映射从普通集合键中隔离；直接集合化会丢失多重性并把冲突实体误分类。
- “命名审计评分”和候选匹配评分目前停留在构成因子/阈值描述，尚未看到权重、归一化、硬门槛、并列候选处理和确定性消歧规则。
- 轻量化稿已有完整的“归一化 → 多层摘要 → 多级闸门 → 候选局部验证 → 语义聚合”主链，但对最终新增/删除/共有/修改的判定仍较概括，未明确候选二分图、互斥匹配、一对多/多对一事件及低置信度待复核集合。
- 轻量化实施例给出孔径变化、倒角新增、位姿归一化等定性过程，尚未看到可复算的实体数、候选数、阈值、评分、混淆矩阵或效率对照。

## Technical closure direction

- 差异结果不能直接由原始 ID 集合差得到；应先构造“可比较实体全集”和“有效命名多重映射”，将确定性同名配对与异常命名配对分流，再在统一匹配关系上计算：
  - 共有/保持不变：已匹配且验证等价；
  - 共有/修改：已匹配但属性、几何、拓扑、参数或语义超过变化阈值；
  - 删除：旧模型实体未被任何有效匹配关系覆盖；
  - 新增：新模型实体未被任何有效匹配关系覆盖；
  - 重命名、分裂、合并：作为匹配关系的特殊基数事件，并与新增/删除避免重复计数。
- 指标至少要区分：单模型覆盖率、双模型联合覆盖率、索引内唯一性、跨版本身份一致性、同名语义冲突率、候选歧义冲突率；否则“覆盖率高”可能掩盖同名误配。

## Proposed common correspondence model

1. 分别按实体层级和业务范围构造可审计实体集合 `U_A`、`U_B`，先统一单位、坐标、容差和实体类型。
2. 对永久名称采用多重映射 `E_X(k)={e}`，不把重复键提前压成普通集合；区分无名称、一个有效名称、多个名称和一个键对应多个实体。
3. 永久命名案先固定可信的一对一同名边；轻量摘要案直接从摘要索引产生候选边。其余对象进入稀疏候选关系图。
4. 候选边经过实体类型等硬约束、多维相似度阈值、最佳/次佳分数间隔和互斥约束消歧；必要时以最大权匹配确定一对一关系，并以受约束组关系表示一对多分裂和多对一合并。
5. 仅对消歧后的候选关系执行局部几何、拓扑、参数、语义或局部 BREP 验证，形成无冲突对应关系 `R=R_11∪R_1m∪R_m1`。
6. 先消费所有已验证关系端点，再计算：
   - 严格共有关系：`COMMON=R_11`；可追踪共有范围还包括 `R_1m`、`R_m1` 的端点；
   - 删除：`DEL=U_A\dom(R)`；
   - 新增：`ADD=U_B\ran(R)`；
   - 保持不变/修改/重命名：按 `R_11` 中身份、名称及综合差异分数分类；
   - 分裂/合并：分别由 `R_1m`、`R_m1` 给出；
   - 差异事件为修改、重命名、分裂、合并、新增、删除及待复核的并集。
7. 强制分区不变量：每个实体只能属于一个最终主分类；重命名且修改可采用“主分类+副标签”或独立复合分类，新增/删除不得与分裂/合并重复计数。

## Proposed difference formulas

- 容差归一化数值差异：`d_num(a,b)=clip((|a-b|-eps_abs)/(eps_abs+eps_rel*max(|a|,|b|)),0,1)`，使容差内差异为0。
- 集合/邻接差异：`d_set(X,Y)=1-|X∩Y|/max(|X∪Y|,1)`。
- 类型或语义差异采用0/1项；出现实体类型不兼容等硬冲突时，不进入普通修改判断。
- 对实际可获得的维度集合 `J(a,b)` 重归一化：`D(a,b)=Σ_{i∈J} w_i d_i / Σ_{i∈J} w_i`，避免缺失维度被错误当成零差异。
- `D≤tau_same` 且无硬冲突时为保持不变；`D>tau_same` 且身份一致时为修改。永久名称变化但身份一致时为重命名或“重命名+修改”。

## Proposed permanent-naming metrics

- 有效命名实体集合 `N_X={e∈U_X: e至少关联一个通过格式、命名域和映射版本校验的键}`。
- 覆盖率：`C_cov,X=Σ w_e·1[e∈N_X]/Σ_{e∈U_X}w_e`；无业务权重时退化为 `|N_X|/|U_X|`。
- 唯一可用覆盖率：统计“实体仅关联一个有效键且该键在模型内仅对应一个实体”的实体占 `U_X` 的比例，和普通覆盖率分开报告。
- 共有唯一键集合 `K_11={k:|E_A(k)|=|E_B(k)|=1}`。每个键的身份一致性评分 `q_k` 只使用身份稳定量、层级/上下文、关系角色和映射来源，不把允许变化的尺寸值直接当作身份冲突。
- 一致性通过率：`R_cons=Σw_k·1[q_k≥tau_cons]/Σw_k`；平均一致性得分：`S_cons=Σw_k q_k/Σw_k`。二者拆开，不再混合成一个公式。
- 单模型重复冲突率：被重复键影响的已命名实体权重占已命名实体权重；跨版本冲突率：`K_11` 中硬身份冲突或 `q_k<tau_conf` 的键权重占比；映射冲突率：未被显式分裂/合并谱系解释的多源多目标冲突映射记录占有效映射记录的比例。
- 综合冲突率仅作为可选展示值，对存在数据的冲突类型重归一化加权；实际路由优先采用各指标联合阈值，避免加权平均掩盖某一类严重冲突。
- 原第一版 `C_pair` 应改名为“直接命名对应覆盖率/命名交叠率”，作为效率指标而非命名可信度硬门槛，避免合法新增/删除导致命名域被错误拒绝。
- 分母为零或指标不可计算时输出“不可计算”并触发摘要回退，不把该值默认为0或100%。

## CN202411354990 / CN119312543A comparison

- 本地 PDF 的申请号为 `202411354990.9`，公开号为 `CN119312543A`，名称为“基于BREP的CAD模型对比方法、设备和存储介质”。
- 其权利要求1主链是：可视化比较；可视化不一致则判定两个模型不同；可视化一致则比较两个模型的 BREP 数据；BREP 一致则判定两个模型相同。

## Strengthened-design internal consistency audit

- `R_1m` 和 `R_m1` 不应只写成普通二元边集合。应定义为组关系或超边：`R_1m⊆U_A×P_+(U_B)` 且目标组基数至少2，`R_m1⊆P_+(U_A)×U_B` 且源组基数至少2；`dom`、`ran` 对组端点取并集。这样才能在拓扑语言上区别谱系组关系与若干彼此无关的一对一边。
- 最终关系必须增加端点互斥不变量：在同一比较层级，`R_11`、`R_1m`、`R_m1` 的模型A端点集合两两不交，模型B端点集合也两两不交；否则同一实体会同时被计为一对一、分裂或合并。
- 当前 `DEL=U_A\\dom(R)`、`ADD=U_B\\ran(R)` 与“低信息/局部BREP读取失败不得确定性报新增删除”不完全一致。需要显式定义 `REVIEW_A`、`REVIEW_B`，并改为 `DEL=U_A\\(dom(R)∪REVIEW_A)`、`ADD=U_B\\(ran(R)∪REVIEW_B)`；待复核端点不得进入确定性新增/删除。
- `COMMON=R_11` 是关系而不是实体集合。建议分别定义严格一对一共有关系 `COMMON_11=R_11`、可追踪旧侧实体 `TRACK_A=dom(R)` 和新侧实体 `TRACK_B=ran(R)`，以避免“共有数量”与“关系数量”混用。
- 语义摘要当前记为 `S_X(e)`，候选相似度又记为 `S(a,b)`，存在符号重名。申请稿应将语义摘要改为 `Q_X(e)` 或 `SEM_X(e)`，保留 `S(a,b)` 专用于候选相似度。
- 关系摘要被描述为邻接“多重集”，但 `d_set` 使用普通集合 Jaccard。应另定义多重集 Jaccard：对计数函数 `c_X(t)`、`c_Y(t)`，交集基数为 `Σ_t min(c_X(t),c_Y(t))`，并集基数为 `Σ_t max(c_X(t),c_Y(t))`。
- 分裂/合并的“任意至少两项满足”门槛偏松。更稳健的实施方式应把修剪域覆盖和度量守恒作为必要条件，再要求支承几何相容、内部新增/删除分界和外部邻接相容中的至少一项，以降低把普通相似实体误认成谱系组的风险。
- 核心目标包含减少完整 BREP 读取，但现有数量实施例只证明候选对压缩，没有给出 BREP 读取量口径。应增加 `rho_pair=|C|/(|U_A||U_B|)`、`rho_brep=B_local/(B_full,A+B_full,B)` 或按实体/数据块权重的读取比例，并记录局部读取字节数、内核查询次数、邻域跳数和读取失败数；没有真实测量时只给公式和“示例数据”标签，不宣称产品实测性能。
- “按需局部 BREP”应再细化为分级升级：高置信摘要关系可先做轻量局部一致性验证；只有候选裕量不足、差异分数接近阈值、分裂/合并候选或硬几何参数需要确认时，才进入局部 BREP 读取集合 `V_BREP`。这比“所有候选都读局部 BREP”更直接支撑减少读取量。
- 局部 BREP 范围应有可审计上限：候选实体、至多 `h` 阶拓扑邻域、所属语义结构及分裂/合并候选组，并可设最大实体数、最大字节数或最大内核查询次数；超限进入待复核或受控全量回退。
- 场景矩阵还可补充周期曲面缝边差异、解析曲面与NURBS等价表达、镜像变换、非流形/几何修复、重复阵列中的同摘要实体、装配发生重排、轻量级别不一致和局部变更引发的拓扑级联，以证明跨内核适应性不是仅靠面积/包围盒。
